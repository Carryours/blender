## 📖 详细使用方法

### 基本命令

```bash
# 基本转换（最简单）
python3 blend2glb.py input.blend -o output.glb

# 详细输出模式
python3 blend2glb.py input.blend -o output.glb -v

# 自动生成输出文件名
python3 blend2glb.py input.blend
# 将生成 input.glb
```

### 高级选项

```bash
# 转换时包含动画
python3 blend2glb.py model.blend -o model.glb --animations

# 转换时包含相机和灯光
python3 blend2glb.py scene.blend -o scene.glb --cameras --lights

# 不导出材质
python3 blend2glb.py model.blend -o model.glb --no-materials

# 不应用修改器
python3 blend2glb.py model.blend -o model.glb --no-apply-modifiers
```

### 批量转换

```bash
# 转换整个目录
python3 blend2glb.py -b input_folder/ -o output_folder/

# 批量转换并包含动画
python3 blend2glb.py -b models/ -o exports/ --animations -v
```

### 查看文件信息

```bash
# 查看基本信息
python3 blend2glb.py --info model.blend

# 查看详细信息
python3 blend2glb.py --info model.blend -v
```

## ⚙️ 所有可用选项

### 导出内容选项

```bash
--materials          # 导出材质（默认启用）
--no-materials       # 不导出材质

--animations         # 导出动画
--cameras           # 导出相机
--lights            # 导出灯光

--uvs               # 导出UV坐标（默认启用）
--no-uvs            # 不导出UV坐标

--normals           # 导出法线（默认启用）
--no-normals        # 不导出法线

--colors            # 导出顶点颜色（默认启用）
--no-colors         # 不导出顶点颜色
```

### 修改器和变换

```bash
--apply-modifiers      # 应用修改器（默认启用）
--no-apply-modifiers   # 不应用修改器
```

### 过滤选项

```bash
--selection         # 仅导出选中的对象
--visible           # 仅导出可见的对象
--renderable        # 仅导出可渲染的对象
--active-collection # 仅导出活动集合
```

### 其他选项

```bash
-v, --verbose       # 显示详细输出

--info              # 显示文件信息
```

## 🐛 常见问题解决

### 问题1：找不到Blender

**错误信息：**
```
未找到Blender安装。请安装Blender或指定blender_path参数。
```

**解决方法：**
```bash
# 方法1: 安装Blender到标准位置
brew install --cask blender  # macOS

# 方法2: 手动指定Blender路径
python3 blend2glb.py input.blend -o output.glb \
  --blender-path "/Applications/Blender.app/Contents/MacOS/Blender"
```

### 问题2：转换失败

**错误信息：**
```
✗ 转换失败
```

**解决方法：**
```bash
# 1. 使用详细输出查看错误
python3 blend2glb.py input.blend -o output.glb -v

# 2. 检查输入文件
python3 blend2glb.py --info input.blend

# 3. 确认文件存在且未损坏
ls -lh input.blend
```

### 问题3：输出文件太大

**解决方法：**
```bash
# 只导出需要的内容
python3 blend2glb.py input.blend -o output.glb \
  --no-cameras \
  --no-lights \
  --no-animations

# 或在Blender中优化模型：
# - 减少多边形数量
# - 压缩纹理
# - 删除不需要的数据
```

### 问题4：权限错误

**错误信息：**
```
Permission denied
```

**解决方法：**
```bash
# 确保输出目录可写
mkdir -p output_folder
chmod 755 output_folder

# 或指定不同的输出位置
python3 blend2glb.py input.blend -o ~/Desktop/output.glb
```

## 💡 使用技巧

### 技巧1：创建别名

在 `~/.zshrc` 或 `~/.bashrc` 中添加：

```bash
alias blend2glb='python3 /Users/pengxin/workspace/blender/blend_to_glb_converter/blend2glb.py'
```

然后就可以直接使用：
```bash
blend2glb input.blend -o output.glb
```

### 技巧2：批量处理脚本

创建 `batch_convert.sh`：

```bash
#!/bin/bash
# 批量转换脚本

INPUT_DIR="input_models"
OUTPUT_DIR="output_models"

python3 blend2glb.py -b "$INPUT_DIR" -o "$OUTPUT_DIR" \
  --apply-modifiers \
  --materials \
  --animations \
  -v
```

### 技巧3：集成到构建流程

在 `Makefile` 中：

```makefile
BLEND_FILES := $(wildcard assets/*.blend)
GLB_FILES := $(patsubst assets/%.blend,build/%.glb,$(BLEND_FILES))

all: $(GLB_FILES)

build/%.glb: assets/%.blend
	python3 blend2glb.py $< -o $@
```

## 🎓 Python API示例

如果您想在Python脚本中使用转换器：

```python
#!/usr/bin/env python3
import sys
import os

# 添加转换器到路径
sys.path.insert(0, 'core')
from converter_v2 import BlendToGLBConverter

# 初始化
converter = BlendToGLBConverter()

if not converter.is_available():
    print("请安装Blender")
    sys.exit(1)

# 单文件转换
success = converter.convert(
    input_path="model.blend",
    output_path="model.glb",
    export_materials=True,
    export_animations=False,
    verbose=True
)

# 获取文件信息
info = converter.get_info("model.blend")
print(f"对象数: {len(info['objects'])}")
print(f"网格数: {len(info['meshes'])}")

# 批量转换
results = converter.batch_convert(
    input_dir="input/",
    output_dir="output/",
    export_materials=True
)

print(f"成功: {sum(results.values())}/{len(results)}")
```
